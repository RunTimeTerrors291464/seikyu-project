# Inventory System – Frontend Skeleton

This is a Next.js 14 + TypeScript + Tailwind starter aligned with the POS/Inventory UI prompts we defined.

## What’s inside
- App Router with an app shell (Sidebar + Topbar)
- Pages: Dashboard, Invoices list, New Invoice, Invoice Detail, Edit
- Tailwind configured (dark-mode class)
- Types for domain models and Zod schemas

## Run locally
1. Install dependencies
```bash
npm install
```
2. Start dev server
```bash
npm run dev
```
3. Open http://localhost:3000
